## Before the studio

Bring the toolchain installed in week 1. If any of the three emulators
didn't install cleanly, say so at the start of studio rather than debugging
it alone.

## In the studio

Three stations, one per platform, each with a supplied game to boot. The
goal isn't depth yet — it's a clean first boot on all three, so that when
something doesn't boot later in the semester you already know what a
*working* setup looks like.

## Afterwards

Keep notes on any platform-specific quirk you hit (a missing BIOS file, a
codec Ruffle doesn't support). You'll likely hit a version of it again once
you're working with your own artifact.
