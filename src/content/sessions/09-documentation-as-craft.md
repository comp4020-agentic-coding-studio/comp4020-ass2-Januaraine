## Before the studio

Bring whatever notes you've kept since week 8, however rough. If you haven't
been logging as you go, today is the point to start — reconstructing three
weeks of work from memory is exactly what week 9's lecture warns against.

## In the studio

Swap notes with another student and try to follow their recovery so far from
the writing alone. Where you get lost or have to ask a question out loud,
that's a gap in their documentation — and you'll do the same for yours.

## Afterwards

Keep logging every session between now and week 11. The exhibit prep studio
assumes this documentation already exists; it doesn't leave time to write it
from scratch.
