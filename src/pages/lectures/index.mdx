Twelve weeks, one throughline: recovering abandoned and obsolete games as
digital archaeological artifacts. Weeks 1–7 build the methods — defining
loss, emulation, file formats, save files, ethics, console preservation —
against a recurring case study. Weeks 8–12 apply them to an artifact you
choose yourself.
