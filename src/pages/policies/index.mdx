# Policies and support

## Late work and extensions

Extensions are granted for documented illness or genuine emergency, on
request before the deadline where possible. For the Field Report, a short
extension is usually workable. For the Recovery Exhibit, the exhibition
component has a fixed date — the session it's presented in — so an extension
there can only cover the written report, not the presentation itself.

## Academic integrity, applied to this course

The usual rules apply, with two points specific to a recovery practicum:

- **Cite your sources like evidence, not like references.** Every claim
  about your artifact — where a file came from, when a build was uploaded,
  what a forum thread said — needs a citation, the same way a fact in an
  archaeological report would.
- **Recovering an artifact is not the same as copying someone else's
  recovery of it.** If a preservation community has already fully
  documented the exact artifact you chose, that's a sign to pick a
  different one, not a shortcut.

## Emulation, ROMs, and this course

This course teaches emulation and archival-access methods as preservation
skills. It does not endorse or require distributing copyrighted material,
and no assessment should ask you to. See [week 6](/lectures/06-abandonware-ethics/)
for the course's full position on copyright, abandonware, and responsible
archival access.

## Getting help

Studio time (see [Studios](/sessions/)) is the fastest way to unstick a
recovery attempt — most problems are easier to diagnose in front of the
artifact than over email. For anything affecting the whole class, contact
the [teaching team](/people/) directly.
